# 飞剑特效

打开 `sword-domain.html`。三个演出都使用 960×400 的完整武道会擂台。时间轴以候选 30 fps 步进。并排看视频时，进度条旁显示候选时间，原片上方显示来源时间。两边共用播放、暂停和速度。网页为指定事件对时，较短的一侧在片头或片尾停帧，两个片段都能看全。

| 无限剑制 | 5.80 秒 | 项目战士 033「无限剑制」。铺出剑场后保留插地的剑。两次出剑分别在 2.02、3.55 秒起动，2.64、4.17 秒到达目标。回合间隔与最后撤场用于网页演示。 |

## 具体参考

- 给图①是 99金馆长《Godot实现仙剑奇侠传-万剑诀》约 4 秒处。核对了 2.000–7.200 秒的全幅原段，首次接触亮斑在源 PTS 3.566688 秒。采用细剑从画面上缘分批进入、落点各自闪亮和留剑收尾。[原片](https://www.bilibili.com/video/BV1XQs26nEPR/?t=3)
- 给图②对应时光明白《重生修仙传》飞剑演示第 225 帧（零基），源片 7.500 秒。5.200–12.000 秒用于剑阵的密度、切向和集束。11.800–28.700 秒用于留地、起剑回卷、再发。原片含剪辑。剑的横版运动轨迹和两段的衔接是本次编排。[原片](https://www.bilibili.com/video/BV1iVm9BFE4Q/?t=7.5)
- 《Fate/Grand Order》美服官方指南 PDF 第 5 页的两张独立实机图，分别用于无限剑制的暮色、齿轮、插地远近层次及横飞方向。网页可点开指南中嵌入的原始图像。[官方指南](https://fate-go.us/howto/pdf/How_to_Play_Fate_Grand_Order_Official_USA_Website.pdf#page=5)
- 《王者荣耀》诸葛亮「鹤羽星尊」官方实机 94.933–98.233 秒。95.700 秒一剑转向，其余飞剑暂留阵内。用于对照单剑出列。[官方实机](https://www.bilibili.com/video/BV1km4y1v7Sh/?t=95)

这些参考用于目视与选帧。三套候选共用程序绘制的飞剑、空间投影和分层，没有调用生图工具。

## 角色与特效

默认剑士来自先前交付的 Ember 透明动作。源为 24 fps、57 张完整人物帧；取原生顺序举剑，阵成时停留在举剑姿势，出手时继续播放。受击方沿用悟空 V4 的站立与受击贴图。角色切换可查看项目现用的战士和对手，姿势及帧长读自 `shinobi/motion.tres` 与 `qi/motion.tres`。「项目现效」复用实际蓄力图集和单剑贴图，在网页按原 0.28 秒飞行时长复现，两个回合对齐候选命中时刻。

在网页中可单独复用 `sword-domain/swords.js`。用 `swordVfx.duration` 和 `swordVfx.events` 取时长及事件。每帧先以 `ground`、`back` 两个 pass 绘制，再绘双方角色，最后以 `front` 绘制。参数 `move` 可取 `unlimited`、`recall` 或 `myriad`，时间单位为秒，`targetX` 指向朝右坐标系的目标，`mirror` 切换施放方向，`hit` 控制命中与落空。
