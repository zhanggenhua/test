# 激光与能量波

先明确参考的视觉任务。细直警戒线、持续激光和需要表现推力的宽能量波，对轮廓、亮芯、端头和持续变化的要求不同。提取对应参考视频或素材里的首发、稳定段和消散帧，合成到游戏角色大小下判断。

## 画面结构

- 发射端贴住出手挂点，通过紧凑亮团、短闪或外扩轮廓传递释放。持续阶段保持视觉连接，跟随动作锚点移动。
- 主体用亮芯、外沿和少量同向运动表现能量流。宽能量波可以试稳定亮芯、前向楔形边缘、向前奔流的纹理。用同屏对照确认轮廓是否比规则圆端、均匀脉冲更适合当前参考。
- 开放端沿运动方向收束、撕裂或散开；命中端用不同轮廓的接触闪和碎片。依据实战是否命中及是否穿透决定显示位置。
- 将释放闪、持续变化和收束分别定时。测试从蓄力到释放的连贯、持续阶段的可循环性及收尾能否归零。

## 制作与接入

- 射程固定且造型复杂时可交付完整透明序列，附出手挂点与逐帧时长。
- 长度变化时，优先拆成可循环束身、发射口和命中端，从出手点向端点组装。束身可裁切、平铺或按长度计算，固定纹理的尺寸和速度以及两端的尺度。近距离要处理两端重叠。空放时给末端独立的收口，命中时将命中特效放在接触点。
- pixelfx 的 `arcane/arcane-beam` 是现成基线。先渲染原样例，再按它的束身、发射口、末端绘制段落拆出独立部件。此样例自带固定长度。给可变射程做独立组装后，用同一组部件从短距拖到长距，检查起点和可见中段的纹理是否稳定，命中层是否跟随端点。多档预渲染成品可比较各档画面，连续变距需要用同一组部件在预览中验证。
- 横版屏幕上的束轴由发射锚点、目标点和实际技能方向共同确定。固定镜头保持屏幕空间的尺度，近口做渐扩，维持段按截面设宽。前后束壳、绕行能量和发射环按该机位投影。
- 从项目提供的技能结果读取视觉端点，区分可穿透的波束、受遮挡的波束和仅视觉演出的波束。对释放、维持和结束使用实际事件。确认左右方向、像素比例、渲染层级和混合方式。
- 验收时保持同样的镜头、角色姿态、接触点与技能时刻，比较开放端和命中端。对可变长度验证近、远与移动，亮色和暗色背景都检查核心与边缘。
