# 三重罗生门 V8

打开 `rashomon-v8.html`。左侧可切换手游选帧和 V7。用「按地」看手掌与鞋底一线，用「三门成阵」查看叠放。门体图鉴提供三道门各自的实机全幅与 2D 素材。

## 来源与驱动

| 对象 | 来源与驱动 |
| --- | --- |
| 游戏实际使用的技能 | 本地《奇怪的蓄波挡》技能 131 使用 `men`。角色由 Godot AnimatedSprite2D 播放 SpriteFrames，`animeMan` 使用 `men`，士兵造型映射到 `Ward`。特效由 `StageFx.burst` 播放 `ward`，基准 0.40 秒。 |
| 手游动作参考 | 《火影忍者手游》晓大蛇丸 2.5D 实机录像，原始选帧 852×480、30 fps。录像先后演示三次独立召门，参考动作是从公开实机画面按阶段采样，源骨骼数据与时长未知。[原片](https://www.bilibili.com/video/BV1NUDmYVE1P/?t=1) |
| 参考素材包 | 本次没有从素材包抽取施法动作。复用了项目的待机图 `assets/ninja/idle.png` 和既有落地砂尘层。 |
| V7 候选 | 豆包 Seedance 2.0 Mini 确认分镜后提示当日免费额度耗尽，未返回 MP4。经同意改用内置 ImageGen，以同一母版逐张生成 6 张完整角色姿势。Canvas 按指定时间播放 6 张新姿势及项目待机图，动作 0.505 秒。 |

每帧只对完整图做等比缩放和平移。检查了黄发、护额、橙衣、右向轮廓、脚底线、按地手掌与首尾衔接。少量发刺和手形来自逐帧重绘，后脚在回重心时有小幅位移。角色无持握装备。七格透明图集每格 172×146，画布左上角放在视口 (44, 190)，局部地线 y=139，手掌接触点为视口 (174, 329)。时间与每帧对应参考见 `v7-cast-manifest.json`。

## 门体与导出

三张门用内置 ImageGen 改绘 V6 的自有透明素材。绿门改成高冠长叶、低黑瓦檐和窄面，蓝门改成下垂蓝石和窄石面，红门改成外翻赤甲和纵向獠牙。三道共用 y=329，中心 x=297、389、481。显示外框依次为 128×171、136×186、134×181。红门遮绿门右侧，绿门遮蓝门右侧。反向施法镜像整组，门体的遮挡关系一致。

`transparent/` 是 69 张 960×400 的独立特效序列，按 30 fps 取样，角色单独在 `caster/`。透明序列含掌边扬尘、门体、破土和收尾。预览使用两条 2D 图层；项目接入另行评估。底尘使用项目 pixelfx 落地特效和 Kenney Smoke Particles，来源许可随包附上。
